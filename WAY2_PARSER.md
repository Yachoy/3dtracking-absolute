# Way2: парсер переписан под новые входные данные — проверьте

Ветка `way2-parser` от `codex/online-tracking` (`aa51f08`). Изменён только разбор входных данных
и добавлены метрики без эталона; трекер не трогали.

## Что поменялось во входных данных Way2 (scene2.7z)

| | Way1 | Way2 |
|---|---|---|
| Камер | 5 | 9 (камера 2 движется: дрон на ~260 м, наклон −49°) |
| Фокус | в шапке CSV: `…;Focal length;35` | колонка `Focal_Length_mm` в каждой строке: 25 / 35 / 50 / 60 мм |
| Матрица | во 2-й строке CSV: `матрица;23,76*13,365мм` | отдельный файл `matrix_size.txt`: `23,76 mm * 13,365 mm` |
| Видео | `Way1.FinalImage.CineCameraActorN.mp4` | `Way2.FinalImage.CineCameraActorN.mp4` |
| Эталон | `object_transform_SM_AA_track.csv` | нет |

Старый парсер на Way2 не находил ни фокус, ни матрицу (`--data` падал с `incomplete calibration`).

## Что изменено в коде

- `core/dataset.py` — `read_transform_csv` читает оба формата: фокус из шапки или из колонки
  `Focal_Length_mm` (построчно, хранится в `Pose.focal_mm` — зум по кадрам поддержан), матрицу из
  строки CSV или из `matrix_size.txt` рядом. `load_scene` находит любое число камер и `*.FinalImage.*.mp4`.
- `core/camera.py` — `Camera.from_track` берёт фокус текущего кадра, если он задан.
- `online/run.py` — манифест камер (`--cameras`) сохраняет построчный фокус.
- `tests/test_way2_format.py` — тесты обоих форматов (`python -m pytest tests` — 13 passed).
- `tools/no_gt_metrics.py` — метрики прогона без эталона (ниже).
- `docs/way2/checks.json` — 4 ручные засечки фуры в двух-трёх камерах.

Проверка калибровки: лучи камер 1 и 2 на фуру в кадре 100 сходятся с зазором 0,4 м, в кадре 1400
(камеры 6 и 9) — 0,05 м. Значит, фокус, матрица и позы камер Way2 читаются правильно.

## Как считать точность без эталона

```bash
python tools/no_gt_metrics.py --out out/way2 --data data/way2 --checks docs/way2/checks.json
```

1. **Засечки** — главное. На нескольких кадрах отмечаем центр фуры в 2+ камерах; лучи из
   калиброванных камер пересекаются в 3D — это независимая оценка положения. `ray_gap_m` — насколько
   точна сама засечка (у нас 0,05–2,7 м), `difference_m` — ошибка трекера на этом кадре.
   На Way1 с эталоном инструмент даёт ту же ошибку, что и эталон (0,68–0,69 м на кадрах 100/400/700).
2. **Физика** — скорость по окну 0,5 с (на Way1: медиана 14,8 м/с при эталонных 14,5), ускорение,
   скачки > 5 м за кадр, разброс высоты от медианы > 5 м.
3. **Режимы трекера** — доля `multi` и самая длинная серия без свежего наблюдения: сотни кадров
   на одном оптическом потоке почти всегда означают ложный захват.

## Результат прогона Way2 (PicoPose + луч на кабину, 1080 Ti)

```bash
python -m online.run --data data/way2 --out out/way2 --sam models/sam2/sam2.1_hiera_tiny --threads 6 --mono-depth --recover-second-view --pico-source vendor/PicoPose --pico-checkpoint vendor/picopose.ckpt --appearance-target models/truck/target.json --cab-ray models/yolo26l-seg.pt --video
```

| | Way1 (для сравнения) | Way2 |
|---|---|---|
| Засечки: средняя ошибка | 0,68 м | **441 м** (180–860 м) |
| Кадров `multi` | 46 % | 2,5 % |
| `flow` (только оптический поток) | 1 % | 71 % |
| Самая длинная серия без детекции | 29 кадров | 314 кадров |
| Скорость > 40 м/с | 15 окон | 437 |
| Высота p5…p95 | 1,4…6,8 м | −41…+23 м |

**Парсер ошибку не исправил: она не в калибровке, а в захвате.** На кадре 6 в камере 1 трекер
цепляется за мелкое пятно на земле (самой фуры в кадре ещё нет), оценивает дальность ~1 км и дальше
сотни кадров ведёт его оптическим потоком. Настоящую фуру хорошо видят дрон (камера 2) и камеры
3, 6, 7, 9, но трекер их почти не использует. Опубликованный прогон на демо даёт ту же картину
(расхождение 56–758 м на своих засечках).

Что чинить дальше (по выгоде):
1. Не принимать первый захват по одной камере, если оценка уходит под землю или за сотни метров
   (высота относительно камер, правдоподобная дальность по размеру маски).
2. Перезахват: свежая уверенная детекция в другой камере должна сбрасывать захват, который ведётся
   только потоком.
3. Детектор на вид сверху (дрон): YOLO плохо видит фуру сверху.
